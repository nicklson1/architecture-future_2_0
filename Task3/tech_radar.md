
## 🚀 Технический радар (Tech Radar)

### Категории:
- **ADOPT** — активно используем и рекомендуем
- **TRIAL** — тестируем, готовы к частичному внедрению
- **ASSESS** — изучаем, возможное внедрение
- **HOLD** — устаревшие или подлежащие замене

| Категория | Технология / Методология         | Назначение / Контекст использования                                       |
|-----------|----------------------------------|---------------------------------------------------------------------------|
| ADOPT     | PostgreSQL / ClickHouse          | Основные хранилища данных в доменах                                       |
| ADOPT     | Power BI                         | BI-визуализация, используется бизнесом                                    |
| ADOPT     | Python (ETL/ML)                  | Скрипты для трансформаций, ИИ-модели                                      |
| ADOPT     | REST/gRPC API                    | Связь между доменами, открытые контракты                                  |
| ADOPT     | Kafka / NATS                     | Событийная шина, асинхронная коммуникация между сервисами                 |
|           |                                  |                                                                           |
| TRIAL     | dbt (Data Build Tool)            | Управление моделями данных                                                |
| TRIAL     | Data Lakehouse (Delta/Snowflake) | Гибрид хранилища и озера, замена DWH                                      |
| TRIAL     | OAuth2 / OpenID Connect          | Унификация авторизации в доменах                                          |
| TRIAL     | draw.io / PlantUML               | Визуализация архитектуры                                                  |
|           |                                  |                                                                           |
| ASSESS    | Airflow / Prefect                | Оркестрация пайплайнов данных                                             |
| ASSESS    | Superset                         | Альтернатива Power BI в доменах                                           |
| ASSESS    | MLOps Stack (MLflow, DVC)        | Управление жизненным циклом моделей ИИ                                    |
|           |                                  |                                                                           |
| HOLD      | Power Builder                    | Устаревший UI, используется в клиниках, подлежит миграции                 |
| HOLD      | SQL Server 2008 DWH              | Централизованное хранилище с жёстко зашитой логикой, подлежит выводу      |
| HOLD      | Apache Camel                     | Старая интеграционная шина, заменяется на API Gateway + Event Bus         |
